# Profile technology icon assets

These SVG icons are vendored into this profile to avoid fragile external
CDN paths and GitHub image-proxy failures. The source files are solid
#7DFFB4; `scripts/build_telemetry_panels.py` embeds them in the hero globe
in each technology's own brand colour (black marks drawn white on the dark
panel).

- Most icons: [Simple Icons](https://simpleicons.org/) SVGs (CC0-1.0),
  retrieved from the public Simple Icons CDN on 2026-10-18. Brand colours
  from the Simple Icons data set.
- `csharp.svg`, `css3.svg`, `visualstudiocode.svg`, and `windows11.svg`:
  [Devicon](https://github.com/devicons/devicon) plain/original shapes (MIT).
- All brand names and marks remain the property of their respective owners.
  This profile is not endorsed by those organizations.
